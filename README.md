A tiny cheerful white robot with a glowing orange visor rides triumphantly on top of a gigantic glowing lightbulb lifting off like a hot-air balloon through a deep indigo dawn sky. Teal, magenta and gold ribbons stream behind it, confetti and speed lines fill the sky, and a small stylised neon city glows at the bottom edge. One huge clear focal shape — the bulb — dominates the frame, so the idea reads instantly even at a glance. This is my entry for the [make.fun ai-excited-01 competition](https://make.fun/bounty/ai-excited-01), where an AI judge picks the image that excites it most.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` into the output directory (default `/output`) as `entry.png`. Node 22, standard library only, no network, fully deterministic — every run writes the same bytes.
